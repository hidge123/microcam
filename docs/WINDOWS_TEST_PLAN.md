# Microcam Windows 手动验收计划

自动测试覆盖脱敏、AES-GCM 完整性、密文落盘、时间聚合、提示词变量和 AI Endpoint 安全规则。以下项目必须在 Windows 11 真机或受支持虚拟机上完成。

## 安装与生命周期

- x64 和 arm64 安装包能在对应架构安装、启动、卸载；便携版不创建安装项，但仍按文档把用户数据保存在 `%APPDATA%\\Microcam`。
- 关闭主窗口后应用仍在通知区域运行；托盘菜单可打开、暂停、恢复和退出。
- 只允许单实例；第二次启动应聚焦已有窗口。
- 启用登录启动后重新登录，应用静默进入通知区域，不自动弹出主窗口。
- 锁屏、睡眠、切换用户和关机时立即结束活动片段；恢复后不补记离开期间的时间。

## 活动采集

- 切换 Win32、UWP、Electron、浏览器和以管理员身份运行的应用，前台应用名最迟 3 秒更新。
- 普通权限运行的 Microcam 无法读取高完整性窗口标题时，仍应记录应用时长且不崩溃。
- 达到空闲阈值后停止计时，恢复输入后重新开始，不补记空闲时长。
- 跨本地午夜正确分段；夏令时切换地区需额外验证一天边界。
- 暂停 15 分钟、1 小时和永久暂停均按预期工作。
- 密码管理器、Windows 凭据界面默认只记录时长；“完全排除”应用不写入活动。

## 隐私与安全

- 用包含邮箱、电话、IPv4/IPv6、URL、Windows/UNC 路径、API Token、用户名和自定义规则的窗口标题测试。
- 在 `microcam.sqlite`、WAL、`settings.json`、`secure-store.json`、控制台和 AI 请求中搜索原始标题，均不得出现。
- 渲染进程 DevTools 中不存在 `require`、`process` 或直接网络能力；CSP 不允许内联脚本和外部连接。
- 修改 AI Base URL 后，发送目标确认自动取消。
- AI 连接测试不包含活动；生成请求只包含按小时、应用和脱敏标题聚合的摘要。
- 彻底重置后活动、日记、API Key、主密钥以外的安全项、自定义规则和设置均清除；重新启动仍可正常记录。

## AI 与调度

- HTTPS Endpoint 与 loopback HTTP 可用，远程 HTTP 在请求前被拒绝。
- 401/403 和响应格式错误不重试；429、5xx、断网最多尝试三次。
- 计划时间休眠时，恢复后下一次调度检查补生成最近一个符合条件的完整日期。
- 同一天不会被多个调度检查重复提交；重新生成失败时保留旧日记。
- Markdown 导出只写用户在保存对话框选择的位置。

## 性能

使用 Windows Performance Recorder 或任务管理器连续观察至少两小时：

- 空闲时主进程与采集子进程合计平均 CPU 目标低于 0.5%。
- 常驻内存稳定，无持续增长；初始目标低于 180 MB。
- 空闲时没有网络请求；SQLite 活动检查点最多每 30 秒一次。
- PowerShell 子进程长期运行，无每次采样重新启动进程的行为。
